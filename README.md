# Digital Forensics & OSINT Laboratory Analysis Reports

This repository contains practical laboratory walkthroughs, methodology documentation, and analysis reports focusing on **Digital Forensics (DFIR)** and **Open Source Intelligence (OSINT)**.

## 🛠️ Tools & Technologies
- **Digital Forensics / Memory Analysis:** FTK Imager, Volatility Framework, Autopsy, MD5/SHA256 Hashing
- **OSINT & Metadata Extraction:** ExifTool, TryHackMe CTF Labs, Linux CLI

---

## 📁 Repository Contents

### 1. Digital Forensics & Evidence Handling
- **RAM Image Acquisition & Analysis (`RAM imaj alma inceleme.pdf`):** Step-by-step procedures for live memory dump collection (`.mem`) and memory artifact inspection.
- **Data Integrity & Hashing (`hash_degeri_alma_compressed.pdf`):** Forensic verification, cryptographic hash computation (MD5/SHA1/SHA256), and integrity checking for physical/digital evidence.

### 2. OSINT & Image Forensics
- **Metadata Analysis Walkthrough (`TryHackMe Ohsınt Odevi.pdf`):** Geolocation, camera metadata extraction, and hidden flag discovery using `ExifTool` and OSINT methodologies on challenge labs.
